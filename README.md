# 100 Days of DevOps (KodeKloud)

<p align="center">
  <img src="assets/cat.gif" width="320" alt="keep climbing">
</p>

Ever since I stepped into software engineering, the one thing I actually knew was how to
write code. Shipping features made me feel productive, but it kept me in one narrow lane.
The further I went, the more I noticed how much lives outside the editor that I'd never
touched: servers, users, permissions, services, networks, deploys. If I want to last in
this field, that gap has to close.

So I'm climbing. 100 days, one task at a time. **Stand up! 🙌**
